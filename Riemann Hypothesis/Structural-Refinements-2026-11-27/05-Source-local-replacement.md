## 1. Exact main-block replacement, not an additional Selmer hypothesis
In [TraceRelations.lean, lines 525–559](https://github.com/lsernau/grh-lean/blob/72fead102f663d5c7a407964a13dc0cf9d977207/grh/src/New/Congruences/FirstOrder/TraceRelations.lean#L525-L559), the proof of length_ribetCocyclesVanishingOn_le sets
$$Z_M=\operatorname{RibetCocyclesVanishingOn}(u,T,O/\ell^M,\operatorname{range}(\mathrm{withConjInv}\,\tau),\gamma),\quad Z_f=\operatorname{obeying}(\operatorname{crysRelations}(T),O/\ell^M).$$
The source proves $Z_M\cap Z_f\subseteq\operatorname{selmerCocycles}(T,Q,M,\gamma)$ by the actual continuous/unramified hypotheses and tame-generator vanishing. The final line first applies exact length additivity and then enlarges relLength(Z_M,Z_f) to the whole Ribet colength. Do not perform this last enlargement. Therefore directly from the same argument
$$\boxed{\operatorname{len} Z_M\le D^{\rm tied}_{\rho,M}+\operatorname{len}\operatorname{selmerCocycles}(T,Q,M,\gamma),\qquad D^{\rm tied}_{\rho,M}=\operatorname{relLength}(Z_M,Z_f).}\tag{C9a}$$
The new quotient is exactly C8, not just a heuristic approximation. Its proof is in 03 §9. The source's passage from every finite M to divisible coefficients in [RibetElement.lean, lines 233–267](https://github.com/lsernau/grh-lean/blob/72fead102f663d5c7a407964a13dc0cf9d977207/grh/src/New/Congruences/FirstOrder/RibetElement.lean#L233-L267) only needs a uniform bound for all M. Thus if $D_\rho^{\rm tied}=\sup_M D_{\rho,M}^{\rm tied}<\infty$, substitute this number for lossT, keeping the original global Selmer length and every other source hypothesis. This recovers the main-block tied determinant with smaller allowance. The original universal defect is one sufficient bound; it need not be used if the relative conductor can be proved independently.

## 2. Exact character-block replacement, including trivial Tate character
For any selected character χ, define $P_\chi=O_\chi\otimes_H I$ with right character action, and crystalline rows $J_\chi\subseteq P_\chi$. No separator or normalization at γ required. For q=ℓ^ν let $P_q=P_\chi/qP_\chi$. A submodule $Z$ of actual Ribet cocycles is a submodule of $\operatorname{Hom}_O(P_q,O/q)$. Define $E_Z\subseteq P_\chi$ as the full inverse image of its annihilator in P_q. Finite DVR duality implies Z is exactly the annihilator of E_Z. Thus
$$\boxed{\operatorname{relLength}(Z,Z_f)=\operatorname{len}\frac{J_\chi+E_Z}{E_Z}.}\tag{C9b}$$
This applies regardless of whether Z is generated by explicit linear evaluation conditions, and avoids mistaking a conditional implication in IsCharacterCocycle for a linear relation.

The actual source [TraceRelations.lean, lines 577–623](https://github.com/lsernau/grh-lean/blob/72fead102f663d5c7a407964a13dc0cf9d977207/grh/src/New/Congruences/FirstOrder/TraceRelations.lean#L577-L623) proves hasTriangleCost_of_isCharacterCocycle. It first verifies h_obey, h_tame, h_g₀, h_unr, then uses hasTriangleCost_tateTwist and enlarges the relation loss with relLength_mono h_obey le_rfl. Retaining the smaller term yields triangle cost
$$\operatorname{relLength}(Z,Z_f)+\operatorname{len}\operatorname{shaOdd}.$$
There is also a uniform substitute independent of the precise Z used by the Fitting construction: let $E_\delta$ be generated by all rows $1\otimes(u(\mathrm{withConjInv}\,\delta)-1)$ for mandatory tame generators. The source h_tame implies $E_\delta+qP_\chi\subseteq E_Z$. Hence
$$\boxed{D_{\chi,\nu}^{\rm tame}:=\operatorname{len}\frac{J_\chi+E_\delta+qP_\chi}{E_\delta+qP_\chi}\ \ge\operatorname{relLength}(Z,Z_f).}\tag{C9c}$$
This includes χ=1. No claim that D_tame vanishes. It can be smaller than full crystallineColength and requires no additional polynomial/spectral separation hypothesis. It is a safe uniform upper bound for all actual Z in this source interface.

## 3. Combined relative conductor budget
For each main representation use C8 and C9a; for each Tate summand use C9c. The source h_loc in RibetElement adds main lossT and character crystalline colengths. The revised sufficient local condition is
$$\boxed{\operatorname{normLength}D_\rho^{\rm tied}+\sum_{e<t'}\operatorname{normLength}D_{\chi_e,\nu}^{\rm tame}\le b_{\ell,\rho}.}\tag{C9★}$$
If independently established, this can replace the source's universal-class bound at the point where it is actually consumed; the original tame and global Selmer costs remain. Weighted global target is $\sum_{\ell,j,\rho}w_{\ell,j,\rho}b_{\ell,\rho}\log\ell=O(fa\log b)$ with actual multiplicities and uniformity in coefficient embeddings. The main loss must be uniform in all truncations M at fixed actual data. Character loss at ν is only needed at that truncation.

A sufficient main-block conductor condition is $c_{\ell,\rho} C_{\rho,\ell}\subseteq T_{\rho,\ell}$ for image of local commutators in K; character condition $c_{\ell,\chi}J_\chi\subseteq E_\delta+qP_\chi$. If each corresponding image has ≤s generators, normalized length≤s vℓ(c). More generally compute Fitting lengths of the actual image rather than product of exponent and generator count. This is finite-dimensional and avoids bounding full representation-algebra discriminants.

## 4. Stress tests and boundary of achievement
- Adding evaluation relations decreases reachable colength but does not give a numerical improvement unless overlap is established on actual data.
- Actual τ and δ cannot be freely chosen: source triangle, tameness and detection constraints must remain. The same global trace relations must be used on both sides.
- A global central projector is sufficient but much stronger than the relative local conductor condition. A generic scalar action on one representation does not bound cross-family extensions (see 03 counterexamples).
- Source exists_tame_relations constructs polynomial annihilators at primes outside ℓ. These do not automatically give relations in local decomposition groups above ℓ.
- For a tame generator δ with χ(δ)=1 and o(u(δ))(u(δ)−1)=0, balancing gives o(1) times its rank-one tensor row =0. If o(1) is a unit the row is already zero; imposing it cannot create savings. Nonunit rows may produce overlap, but the overlap with crystalline rows still needs proof.
- The source-relative replacement of the length inequalities is now explicit, but no independent global conductor bound has been established.
